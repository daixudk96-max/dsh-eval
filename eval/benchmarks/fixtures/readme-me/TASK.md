# Readme Me

A tiny calculator module with no documentation. Write the README.

Files:

- `src/calc.js` — exports `add`, `multiply`, `div`. Note: `multiply`
  validates its inputs (throws `TypeError`), `div` rejects division by
  zero.
- `check.js` — the grading script (do NOT modify it).

## Your task

1. Read `src/calc.js`.
2. Write `README.md` documenting the module: a one-line description, a
   usage example (`import { multiply } from './src/calc.js'` etc.), and
   a note about error handling.
3. You do not need to run any tests; the grading reads README.md only.

The grading check requires the README to mention `multiply`, include a
usage example, and cover error handling — a generic README fails.
