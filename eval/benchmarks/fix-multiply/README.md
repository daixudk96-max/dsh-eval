# Fix Multiply

A tiny buggy JavaScript module. Fix it so its test passes.

Files:

- `src/multiply.js` — the module to fix. It currently returns `a + b`
  instead of the product.
- `tests/run.js` — the test runner: asserts `multiply(3, 4) === 12` and
  prints PASS/FAIL.
- `check.js` — the grading script (do NOT modify it).

## Your task

1. Read `src/multiply.js` and fix the bug so `multiply(a, b)` returns the
   product `a * b`.
2. Run the test: `node tests/run.js`. It must print `PASS`.
3. Write a short file `ANSWER.md` (2-5 sentences) explaining what was
   wrong and what you changed.

Do not modify `check.js` or the test file.
